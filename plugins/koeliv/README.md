# Koeliv

Les chiffres de votre boutique dans Claude : ventes Shopify, publicité Google, stock et site, lus avec la fiche de
votre boutique préparée avec Koeliv. Demandez par exemple « mes ventes de la semaine dernière » ou lancez la
routine « revue_hebdo_pub ».

Réservé aux clients de Koeliv. Après l'installation, connectez le connecteur Koeliv depuis l'onglet Connecteurs du
plugin, avec l'adresse e-mail donnée à Koeliv : un code de connexion vous est envoyé par e-mail.

Données : le plugin lit les chiffres de votre boutique sur les serveurs de Koeliv, en lecture seule, et n'envoie à
Koeliv que les questions posées aux outils (période, produit). Il ne stocke rien lui-même.
